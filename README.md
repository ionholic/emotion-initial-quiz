# 감정 단어 초성퀴즈

초성을 보고 감정 단어를 맞히는 아동용 HTML 퀴즈 게임입니다.

## 게임 방법

1. 처음에는 감정 단어의 초성만 제시됩니다.
2. 시간이 지나면 그 감정을 느낄 수 있는 상황이 공개됩니다.
3. 시간이 더 지나면 감정 단어의 의미가 공개됩니다.

## 주요 기능

- 감정 단어 90문제
- 5문제, 10문제, 20문제 선택
- 단계별 상황·의미 힌트
- 빠르게 맞힐수록 높은 점수
- 같은 초성의 다른 감정을 첫 단계에서 정답으로 인정
- 데스크톱과 모바일 지원
- 별도 설치나 서버가 필요 없는 단일 HTML
