# 초성퀴즈 시리즈

시간이 흐르면 힌트가 단계적으로 열리는 아동용 HTML 초성퀴즈 게임입니다.

## 플레이

- [감정 단어 맞히기](https://ionholic.github.io/emotion-initial-quiz/): 감정 단어 90문제
- [과자 이름 맞히기](https://ionholic.github.io/emotion-initial-quiz/snacks/): 과자 이름 60문제, 오답 재도전 지원
- 아이스크림 이름 맞히기: 준비 중
- 동물 맞히기: 준비 중

## 게임 방법

1. 처음에는 초성만 제시됩니다.
2. 시간이 지나면 상황·모양 등의 첫 번째 힌트가 열립니다.
3. 시간이 더 지나면 뜻·맛 등의 두 번째 힌트가 열립니다.

모바일과 데스크톱에서 실행되며 별도 서버나 설치가 필요 없는 단일 HTML 게임입니다.

## 새로 개선된 기능

- 문제 진행 막대
- 버튼 또는 `P` 키로 일시정지
- 탭을 벗어나면 자동 일시정지
- 헷갈린 문제와 시간초과 문제 자동 복습
- 복습 문제만 다시 풀기
- 자주 헷갈리는 맞춤법과 한 글자 오타에 대한 재입력 안내
- 정답 글자 수에 맞춘 낱글자 입력칸
- 오답에서 위치가 맞는 글자를 남기고 빈칸만 재입력

자세한 발전 계획은 [IMPROVEMENTS.md](./IMPROVEMENTS.md)에서 확인할 수 있습니다.

문제 데이터의 초성·중복·누락 검사는 `node scripts/audit-quiz-data.mjs`로 실행할 수 있습니다.
